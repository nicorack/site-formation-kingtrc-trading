# Remix of SkillSpark Academy

Création d’un site web de formation en ligne

1. Présentation du projet

Ny tetikasa dia famoronana site web de formation en ligne matihanina, mora ampiasaina, azo antoka, ary natao hivarotana sy hampianarana cours en ligne amin’ny endrika vidéo, PDF, quiz, ary modules.

Ny tranonkala dia tsy maintsy:

 manolotra formations amin’ny fomba mazava sy manintona,

 mamela ny mpampiasa hisoratra anarana sy hividy formation,

 mamela ny admin hitantana mora foana ny contenus,

 miasa tsara amin’ny téléphone, tablette, ary ordinateur,

 azo havaozina sy ampitomboina amin’ny ho avy.

2. Objectifs du site

Ny tanjon’ilay site dia:

 hivarotra formations en ligne,

 hanangana image de marque matihanina,

 hanamora ny fianaran’ny mpianatra amin’ny alalan’ny espace personnel,

 hanome dashboard ho an’ny admin hitantanana ny contenus sy ny utilisateurs,

 hanamora ny fandoavana sy ny fidirana amin’ny cours.

3. Cibles

Ny site dia kendrena ho an’ireto:

 étudiants,

 freelancers,

 entrepreneurs,

 personnes mitady compétences digitales,

 olona te hianatra à distance.

5. Fonctionnalités attendues

5.1. Fonctionnalités côté visiteur

 consulter les formations disponibles,

 voir le prix, la description, le programme et les objectifs,

 rechercher une formation par mot-clé ou catégorie,

 voir les avis/témoignages,

 s’inscrire à la newsletter,

 contacter l’équipe via formulaire ou WhatsApp.

5.2. Fonctionnalités côté apprenant

 créer un compte,

 se connecter / se déconnecter,

 acheter une ou plusieurs formations,

 accéder à un espace personnel sécurisé,

 suivre l’avancement de la formation,

 regarder les vidéos,

 télécharger les supports PDF si autorisé,

 passer des quiz ou tests,

 recevoir un certificat de fin de formation (optionnel),

 voir l’historique des achats,

 modifier son profil.

5.3. Fonctionnalités côté administrateur

 ajouter / modifier / supprimer une formation,

 créer des catégories,

 organiser les cours en modules et leçons,

 uploader vidéos, PDF, images,

 définir le prix normal et promotionnel,

 activer ou désactiver une formation,

 gérer les utilisateurs,

 suivre les ventes,

 voir les statistiques (inscriptions, paiements, formations les plus vendues),

 envoyer des emails ou notifications,

 gérer les témoignages,

 créer des codes promo.

6. Structure d’une formation

Chaque formation doit contenir:

 titre,

 image de couverture,

 description courte,

 description détaillée,

 objectifs pédagogiques,

 public cible,

 niveau (débutant / intermédiaire / avancé),

 durée estimée,

 prix,

 modules,

 leçons,

 vidéos,

 documents téléchargeables,

 quiz / exercices,

 certificat (si activé).

7. Espace élève

L’espace élève doit permettre:

 de voir toutes les formations achetées,

 de reprendre là où il s’est arrêté,

 de suivre la progression en pourcentage,

 de consulter les modules verrouillés/déverrouillés,

 de télécharger certains supports,

 de recevoir des notifications,

 d’avoir une interface simple et claire.

8. Paiement

Le site doit intégrer des solutions de paiement adaptées.

Moyens de paiement recommandés

Mobile Money (Orange Money, MVola, Airtel Money)

Carte bancaire (si possible)

PayPal (optionnel)

virement bancaire (optionnel)

Exigences

 confirmation automatique ou semi-automatique du paiement,

 génération de reçu ou confirmation,

 accès automatique à la formation après validation du paiement,

 historique des transactions côté admin.

9. Design et expérience utilisateur

Le design doit être:

 moderne,

 professionnel,

 responsive,

 rapide à charger,

 simple à naviguer,

 rassurant pour favoriser l’achat.

Recommandations design

 page d’accueil claire avec CTA fort,

 couleurs cohérentes avec la marque,

 typographie lisible,

 boutons visibles,

 mise en avant des bénéfices des formations,

 espace de témoignages pour rassurer,

 design optimisé pour mobile.

10. Exigences techniques

Le site doit:

 être responsive,

 être sécurisé,

 être optimisé SEO,

 charger rapidement,

 permettre une évolution future,

 être simple à administrer.

Technologies possibles

Frontend : Next.js / React

Backend : Node.js / API

Base de données : PostgreSQL / MySQL

CMS custom ou dashboard admin personnalisé

Hébergement : Vercel, Hostinger, LWS, VPS

Stockage vidéos : Vimeo privé, Bunny Stream, Cloudinary, AWS S3 ou autre

11. Contraintes de sécurité

 authentification sécurisée,

 protection des comptes utilisateurs,

 accès privé aux formations achetées,

 protection des vidéos contre le téléchargement direct si possible,

 sauvegardes régulières,

 certificat SSL,

 conformité minimale sur la protection des données.

12. Référencement SEO

Le site doit être optimisé pour:

 les titres SEO,

 meta descriptions,

 URLs propres,

 vitesse de chargement,

 compatibilité mobile,

 balises H1/H2/H3,

 images compressées,

 structure claire pour Google.

13. Contenus à préparer

Le client devra fournir:

 logo,

 couleurs de la marque,

 textes de présentation,

 liste des formations,

 vidéos,

 PDF/supports,

 photos ou visuels,

 coordonnées de contact,

 moyens de paiement disponibles,

 témoignages si disponibles.

14. Livrables attendus

Le prestataire devra livrer:

 site web complet fonctionnel,

 back office administrable,

 système d’inscription/connexion,

 système de paiement,

 espace élève,

 intégration des premières formations,

 documentation d’utilisation,

 formation rapide à la prise en main admin.

16. Critères de réussite

Le projet sera considéré comme réussi si:

 le site fonctionne correctement sur mobile et desktop,

 les utilisateurs peuvent s’inscrire sans problème,

 les paiements sont opérationnels,

 les formations sont accessibles après achat,

 l’admin peut gérer facilement les contenus,

 le site est professionnel et rassurant,

 le temps de chargement reste correct.
